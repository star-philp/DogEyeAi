# 1. Git 커밋 주기 단축
git add .
git commit -m "feat: 실시간 기능별 업데이트 커밋 20250104"
git commit -m "feat: 실시간 기능별 업데이트 커밋 20250201"
 
원격 저장소 추가:
git remote add origin <your-repository-url>
예: git remote add origin https://github.com/yourusername/yourrepository.git

원격 저장소가 제대로 추가되었는지 확인:
git remote -v

그 다음 다시 push 시도
git push origin main
